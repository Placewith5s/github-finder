# github-finder
Get GitHub profile info such as all public repository descriptions.

## Usage
[GitHub Finder](https://placewith5s.github.io/github-finder/)

### Not Shown By Default
- Forked repositories
- Archived repositories

> [!TIP]
> Simply check the box to show the corresponding repositories.

> [!NOTE]
> This app doesn't expose any private repositories
>
> This app doesn't support showing organizations, only users
